## 1. ภาพรวมและขอบเขต

**โจทย์:** เทียบข้อความบนอาร์ตเวิร์ก 2 ไฟล์ (🅰 ต้นฉบับ ↔ 🅱 ฉบับแก้/งานพิมพ์/ภาพถ่าย) ทีละ **คู่โซน**
ที่ผู้ใช้วาด แล้วชี้ว่าต่างตรงไหน พร้อมกรอบบนภาพและ % ความมั่นใจ

**หลักการ 3 ข้อที่ค้ำทั้งระบบ**

| หลัก | ผลต่อการออกแบบ |
|---|---|
| OCR ไม่นิ่ง — แต่ **ภาพเดิมให้ผลเดิม** (วัด 10/11 คู่เหมือนทุกคำ) | ความต่างข้ามรอบมาจากการวาดโซนใหม่ ⇒ ไม่ทำ "อ่าน 2 รอบแล้วโหวต" |
| ผลที่ผิดแบบมั่นใจแย่กว่าไม่แสดง | ไม่มั่นใจ ⇒ **เหลือง** ไม่ใช่แดง · ไม่มีกรอบ ⇒ ไม่เดาตำแหน่ง |
| ไม่มีชั้นไหน "ลบ" จุดต่าง | ชั้นกรอง (ภาพเหมือน/เศษ/ยกเว้น/AI ว่าเป็นสัญญาณรบกวน) **พับลงรายการพับ** พร้อมเลขจุด ยังเห็นได้เสมอ |

**แยกจากโหมด `artwork_check` 100%** — ไม่ import โค้ดเดิม (มีเทสต์ล็อก) · ข้อมูลอยู่ `data/artwork_v2/` (gitignore)
แตะของกลางแค่ 4 จุด: blueprint ใน `app.py` · ลิงก์เมนูใน `base.html` · สิทธิ์ `inspect_artwork` ใน `auth/access.py` · `.gitignore`

**ความสามารถหลัก (ณ วันนี้)**
- OCR: Google Cloud Vision `DOCUMENT_TEXT_DETECTION` (`builtin/stable`, endpoint `eu-vision.googleapis.com`) เรียกตรงด้วย `requests`
- เทียบด้วยอัลกอริทึม (ไม่ใช้ AI เป็นค่าเริ่มต้น) + ชั้นโครงสร้าง (จับคู่ตามตำแหน่ง) + **หลักฐานภาพ** (PDF↔PDF)
- AI ตรวจทาน (Gemini ผ่าน N8N) 3 โหมด — **ปิดเป็นค่าเริ่มต้น**
- วาดโซนแบบหน้า Artwork เดิม (ซูม/เลื่อน/หมุน/ย่อขยาย/ลูกศร) · พื้นที่ยกเว้น · หมุนโซนก่อนส่ง
- ผล: ตารางข้างภาพ · ชี้แถว = ภาพทั้งสองซูมไปที่จุด · ปุ่มรีวิว ✓/⚑ ต่อจุด · Log คัดลอกได้ (ไม่มีกุญแจ)

## 3. การใช้งานบนหน้าเว็บ

เมนู **"Artwork V2"** (`/artwork_v2`) แบ่ง 4 การ์ด:

1. **ตั้งค่า** — กุญแจ (กรอก/ทดสอบ/ลบ) · ปุ่มทดสอบกุญแจกดได้ทีละครั้ง + พัก 5 วิ
2. **อัปโหลด** 🅰/🅱 (PDF/ภาพ ≤ 200 MB) · "เปิดงานเดิม" (รายการงานล่าสุด) · เปิดหน้าใหม่ ⇒ **ถามก่อน** ว่าจะเปิดงานที่ค้างไหม (ไม่กู้คืนเงียบ ๆ)
3. **วาดโซน** — ค่าเริ่มต้น 🖐 เลือก/เลื่อนภาพ · ✏️ วาดโซน (1 โซนแล้วกลับ · ติ๊ก "วาดต่อเนื่อง" = ค้าง) · ⛔ พื้นที่ยกเว้น ·
   ซูม 10–400% (ล้อเมาส์ · พอดีความกว้าง/ทั้งหน้า/100%) · ปุ่มกลาง/Space ลาก = เลื่อนภาพ · ลูกศร = ขยับโซน 1 px (Shift ×10) ·
   Delete ลบ · ↻ หมุนจอต่อไฟล์ · ชิป ↻N° ที่มุมโซน = มุมรายโซน · ภาพตัวอย่าง "ที่จะส่ง" ใต้รายการคู่ ·
   ตัวเลือกก่อนตรวจ: **ภาพที่ส่ง** (มาตรฐาน 400 dpi / คมสูงสุด-ทดลอง) · **สีของภาพ** (สี/เทา/ขาวดำ) · **AI ตรวจทาน**
4. **ผล** — แถบผลตัดสิน · การ์ดต่อคู่ (ภาพ 🅰 | ภาพ 🅱 | ตาราง) · คำอธิบายสัญลักษณ์ · แถบรีวิว · รายการพับ · ปุ่ม "คัดลอก Log"

**ในตารางผล**
- เรียง แดง → เหลือง → เศษ → พับ (ลำดับเดิมภายในระดับเดียวกัน)
- จุดที่อยู่บรรทัดเดียวกัน (ข้อความ A/B ตรงกัน) รวมเป็นแถวเดียว `#5·6·7` — กรอบบนภาพยังแยกต่อจุด
- ชี้แถวค้าง 120 ms ⇒ ภาพ 🅰/🅱 ซูมไปที่กรอบ · คลิก = ค้างซูม · Esc/คลิกที่อื่น = ปล่อย
- จุดหาย/เกินฝั่งเดียว ⇒ ฝั่งที่ไม่มีข้อความซูมไป **ตำแหน่งประมาณ** (กรอบประสีส้ม + ข้อความบอกว่าไม่ใช่ตำแหน่งที่วัดได้) — ไม่มีคู่ยึดพอ ⇒ ไม่ให้ตำแหน่ง
- ⓘ = เปิดหมายเหตุ/ภาพหลักฐาน/คำตอบ AI ของแถว · ⓘ ที่หัวตาราง = เปิดทั้งหมด
- ✓ ยืนยัน / ⚑ รายงานปัญหา ต่อจุด (ดูข้อ 13 — **ความหมายยังรอยืนยัน**)

## 4. Pipeline ทีละขั้น

`pipeline.run()` ห่อ `_run()` — ล้มก่อนยิง Vision ⇒ ลบโฟลเดอร์รอบทิ้ง · ล้มหลังยิงแล้ว ⇒ เก็บ `raw/` ไว้ไล่ปัญหา

| # | ขั้น | โมดูล | สิ่งที่ต้องรู้ |
|---|---|---|---|
| 0 | ด่านกันยิงรัว | `runguard` | งานเดียวกันกำลังวิ่ง ⇒ 409 · ทั้งเครื่องเกิน 2 ⇒ 429 · เพิ่งจบไม่ถึง 3 วิ ⇒ 429 + Retry-After · **ปฏิเสธ ไม่เข้าคิว** |
| 1 | เรนเดอร์ภาพโซน | `imaging` | **ส่งเฉพาะภาพในโซน** · PDF เรนเดอร์เป็นภาพเสมอ (ข้อความซ่อนไม่ติดไป) · ภาพถ่ายหมุนตาม EXIF · หมุนตาม `rotate` ของโซน · สี/เทา/ขาวดำ · JPEG 4:4:4 · ลดคุณภาพก่อนย่อ และบอกทุกครั้งที่ย่อ · คู่ที่เกินงบ ⇒ เข้ารหัสใหม่เฉพาะฝั่งที่เกิน (`pair_refit`) |
| 2 | Vision | `vision_client` | **1 คู่ = 1 คำขอ** (A/B โมเดลรุ่นเดียวกัน) · ≤ 16 ภาพ / ≤ 9.5 MB · ลองซ้ำ 429/5xx/ต่อไม่ติด · error ต่อภาพใน 200 ⇒ ภาพนั้นอ่านไม่ได้ |
| 3 | ประกอบบรรทัด | `textmodel` | Vision ไม่มีวัตถุบรรทัด ⇒ ประกอบจาก `detectedBreak` · เติมพิกัด 0 ที่ JSON ละ · ข้ามบล็อก PICTURE/BARCODE/RULER |
| 3 | เทียบ | `compare` + `structure` | ต่อแถวจุดไข่ปลา → แยกบรรทัดที่รวมข้ามคอลัมน์ → จับคู่ตามตำแหน่ง (Geo) → ต่อชิ้นที่ถูกแยก → หาจุดต่าง → จัดชนิด/ระดับ → โค้ง/เศษ/ย้ายที่/ย้ายบรรทัด → `word_box` / `est_box` |
| 3b | พื้นที่ยกเว้น | `pipeline.apply_ignore` | จุดที่ทุกฝั่งที่มีกรอบอยู่ในพื้นที่ ≥ 60% ⇒ `excluded` |
| 4 | อ่านซ้ำ (ปิดอยู่) | `pipeline._reread` | ครอปรอบคู่บรรทัด ×2 แล้วยิง Vision ซ้ำ · **ปิดเพราะกิน ~90% ของภาพที่ส่ง** |
| 5 | เลขจุด | `pipeline` | การ์ดโค้งยุบเป็นใบเดียว (`members` ครบ) · เลขต่อเนื่อง findings → debris → relocated → excluded |
| 6 | AI | `ai_review` | assist / judge / raw · N8N ล่ม ⇒ ผลอัลกอริทึมทุกรายการ + คำเตือน · แล้ว `apply_ignore` อีกรอบ (จุดที่ AI เพิ่ม) |
| 6b | หลักฐานภาพ | `pixverify` | PDF↔PDF เท่านั้น · ทาบโซน (ORB+ECC) → เรนเดอร์ไฟล์ต้นฉบับ ≤ 1600 dpi ต่อจุด → เทียบหมึก · **SAME** ⇒ `pixel_same` + ภาพ `img/pv<id>.jpg` · DIFF ⇒ "ภาพยืนยันว่าต่าง" · ตรวจไม่ได้ ⇒ ไม่แตะ · เพดานเวลา 180 วิ |
| 7 | ผลตัดสิน + บันทึก | `pipeline.verdict_of` · `diaglog` | `confidence` ทุกจุด = ต่ำสุดของ Vision ในตัวอักษรที่ต่าง · `result.json` + `log.txt` |

## 6. ชนิดจุดต่างและระดับความรุนแรง

| ชนิด (`class`) | ความหมาย | ระดับ |
|---|---|---|
| `NUMBER` | ตัวเลขต่าง (`1.5g`/`15g` · `1,000`/`1.000` ด้วย) | แดง (ถ้า Vision ≥ 0.80 ทุกฝั่ง) |
| `CASE` | ต่างแค่ตัวพิมพ์ใหญ่-เล็ก | แดง |
| `TEXT` | ตัวอักษรต่าง | แดง |
| `PUNCT` | เครื่องหมายต่าง (รวม `" ' \| # *` และเครื่องหมายที่เป็นคำเดี่ยว) | **เหลือง** เว้นแต่การอ่านซ้ำยืนยัน (อ่านซ้ำปิดอยู่ ⇒ เหลืองเสมอ) |
| `FILLER` | มี/ไม่มีจุดไข่ปลา/เส้นตกแต่ง | เหลืองเสมอ |
| `FRACTION` | `½`/`1/2`/`2`/หาย ที่ทำให้บรรทัดเท่ากัน | เหลืองเสมอ ⚠️ |
| `MISSING_IN_B` / `EXTRA_IN_B` | บรรทัด/ข้อความมีฝั่งเดียว | แดง/เหลืองตามความมั่นใจ · ได้ `est_box` |
| `CURVED` | การ์ดรวมจุดบนข้อความโค้ง/เอียง (`members` ครบ) | แดงได้เฉพาะเมื่ออ่านซ้ำยืนยัน ⇒ ปัจจุบันเหลือง |
| `MOVED` | ข้อความย้ายที่ในบรรทัด | เหลือง (ส่วนที่เหลือตัดสินใหม่) |
| `PLACEHOLDER` | ช่องว่างรอพิมพ์ (`xxxxxx` · `XX/XX/XXXX` · TBD/TBC/TBA) ↔ ข้อมูลจริง ≥ 3 ตัว (8 ต.ค.) | **แดง** เมื่อ Vision มั่นใจฝั่งช่องว่าง ≥ `CONF_LOW` (ต่างแน่นอน แม้อ่านรหัสฝั่งข้อมูลจริงไม่มั่นใจ) · ไม่งั้นเหลือง |

**`reflow_unbalanced` (8 ต.ค.)** — ชิ้นท้าย/หัวบรรทัด (หรือบรรทัดที่ไม่มีคู่) ที่ "เจอในบรรทัดข้างเคียงของอีกฝั่ง" เดิมถูกทิ้งเป็น
การตัดบรรทัดเสมอ ⇒ ตอนนี้ต้อง **อนุรักษ์จำนวน** ทั้งโซน (คำเต็ม = นับเป็นคำ · ส่วนของคำ = นับสตริง · เครื่องหมายเบา `, . ; : ' " - · • |` = กติกาเดิม)
· ไม่สมดุล ⇒ เป็นจุดต่าง **เหลือง** + หมายเหตุ "จำนวนครั้งที่ปรากฏทั้งโซนไม่เท่ากัน" (`REFLOW_UNBALANCED_YELLOW=0` ⇒ แดงตามความมั่นใจ)

**รายการพับ (ไม่นับในผลตัดสิน · มีเลขจุด · เห็นบนหน้าเว็บ/Log)**
`debris` (เศษอักขระ) · `relocated` (อยู่อีกบรรทัดตรงตำแหน่งเดียวกัน) · `pixel_same` (ภาพเหมือนกัน + ภาพหลักฐาน) ·
`excluded` (พื้นที่ยกเว้น) · `ai_dismissed` (AI บอกสัญญาณรบกวน — judge/raw) · `algo_only` (อัลกอริทึมพบแต่ AI ไม่ระบุ) ·
`lowmark` (8 ต.ค. — เครื่องหมาย `PUNCT` เดี่ยว **ฝั่งเดียว** ที่ Vision มั่นใจตัวเครื่องหมาย < `CONF_LOW` · ไม่ติดตัวเลข · ไม่ใช่ `* % ® © ℮ # ° ± < > ≤ ≥ ‰ №` ·
ไม่อยู่บนข้อความโค้ง · มักเป็นเส้นไดคัท/ขอบกราฟิก)

**กรอบบนภาพ:** `word_box` = กรอบคำเต็ม เส้น 1.25 px เผื่อ 22% ความสูงคำ · ตัวอักษรที่ต่าง = แถบสีโปร่ง · จุดแทรก = แถบแคบ
(ไม่มี `word_box` โดยตั้งใจ — ครอบคำข้าง ๆ = ชี้ผิดคำ)

## 7. ผลตัดสิน

`pipeline.verdict_of()` — ลำดับความสำคัญ:

| ผล | เงื่อนไข |
|---|---|
| **FAIL** | มีแดง ≥ 1 |
| **UNREADABLE** | ฝั่งใดอ่านไม่ได้ (**ห้าม PASS**) |
| **REVIEW** | มีเหลือง หรือความครอบคลุม < 90% (`COVERAGE_MIN`) — raw ที่สำเร็จไม่ใช้ความครอบคลุม |
| **PASS** | ที่เหลือ — ข้อความ "ไม่พบจุดต่างในข้อความที่ตรวจ" |

**`artwork_v2_eval.py`** (8 ต.ค. · อ่านอย่างเดียว · ไม่ยิง Vision/AI) — เล่นซ้ำผลดิบของรอบตรวจ (`runs/run_NNN` ตรง ๆ หรือโฟลเดอร์
`p<N>_<a|b>.json[.gz]` + `zones.json`) ตามลำดับเดียวกับ pipeline (+ หลักฐานภาพถ้ามีไฟล์ต้นฉบับ) แล้ว **เทียบเฉลย**

= เล่นซ้ำสองชุดแล้วบอกจุดที่เปลี่ยน · `--hints` = แนะนำ `LANGUAGE_HINTS` จากภาษาที่ Vision ตรวจพบ (ภาษาที่ไม่ใช่อักษรละติน ≥ 20 คำ + `en`)

### 13.3 🟡 ข้อจำกัดที่ยอมรับแล้ว

- หลักฐานภาพ **PDF↔PDF เท่านั้น** (ภาพถ่าย/ทาบไม่ติด ⇒ ไม่แตะ) · การแก้ < 0.005 mm² จับได้บางส่วน · สีที่ความสว่างเท่าเดิมมองไม่เห็น
- **AI ไม่เห็นภาพ** — สิ่งที่ Vision อ่านผิดเหมือนกันสองฝั่ง AI ก็ไม่เห็น
- **อ่านซ้ำใช้ Vision ตัวเดียวกัน** ⇒ ไม่ใช่หลักฐานอิสระ (และปิดอยู่)
- **รีวิวผูกกับรอบตรวจ** — ตรวจใหม่ = เลขจุดใหม่ = รีวิวใหม่
- **runguard อยู่ในหน่วยความจำ** — รีสตาร์ตแล้วเวลาพักหาย (ถูกต้อง)
- กรอบคำใช้กรอบตัวอักษรของ Vision ⇒ ข้อความเอียง/โค้งได้กรอบแนวแกนที่ใหญ่กว่าคำ
- จุดที่ AI เพิ่มเข้ามาไม่มี `est_box` · หน้าที่มีบรรทัดตรงกันแค่ 1 บรรทัด ⇒ ไม่ให้ตำแหน่งประมาณ
- "คมสูงสุด" + เทา/ขาวดำ ⇒ ถอยเป็น 400 dpi (งบคิดจากภาพสี)

### 13.4 🔵 ใช้งาน / หน้าตา

- `PREVIEW_MAX_SIDE` 2000 px ⇒ ซูมเกิน ~100% ภาพตัวอย่างเบลอ (ภาพที่ส่ง Vision เรนเดอร์ใหม่เสมอ — ไม่กระทบผล)
- แถวกลุ่ม (`LINE_GROUP`) ยังไม่แสดงภาพหลักฐาน (แถวเดี่ยว/รายการพับแสดง)
- ป้ายเลขกรอบอาจทับบรรทัดบนเล็กน้อยในตารางแน่น · โหมด `BOX_STYLE=span` ป้ายเลขขยายตามซูม
- จอ 1366 px: คอลัมน์ 🅰/🅱 ในตารางข้างภาพกว้าง ~90 px (ปุ่มรีวิวแนวตั้งกินที่) · ข้อความยาวตัดหลายบรรทัด
- ภาพหน้าจอ 400 px เห็นเมนู `base.html` (ของกลาง ไม่ใช่ V2) ซ้อน — ไม่ได้แตะ
- ยังไม่มี: หมุนอัตโนมัติ (เดาทิศจาก OCR) · สถานะรีวิวในรายการ "งานล่าสุด" · สถิติรีวิวข้ามงาน
