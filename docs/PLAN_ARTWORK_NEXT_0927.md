   หรือต้องการ `warning` (ขึ้น REVIEW)?
3. **ขอบเขตภาษา:** เฉพาะสคริปต์ RTL (อาหรับ/เปอร์เซีย/ฮีบรู) เทียบกับบรรทัดละติน —
   ต้องรวมไทยด้วยไหม (`999/9` ของไทยก็เป็นเลขที่บ้านแบบเดียวกัน)
4. **ขอบเขตเครื่องหมาย:** แค่ `/` หรือรวม `-` (เช่น `02-03`) — แนะนำ `/` อย่างเดียวในรอบแรก

### B.3 Phase 0 — วัดก่อนสร้าง (ไม่มีโค้ด production)

**เป้า:** ตอบให้ได้ว่า *"Gemini คืนลำดับตัวเลขในบรรทัดอาหรับตรงกับที่ตาเห็นบนภาพไหม
และนิ่งไหม"* — ถ้าไม่ตรงหรือไม่นิ่ง ชั้นนี้ **ใช้ไม่ได้** ไม่ว่าจะเขียนดีแค่ไหน

1. **ทำ PDF ทดสอบที่รู้คำตอบ** (สคริปต์ใน `scratchpad` หรือ `tools/`):
   * บรรทัดอาหรับ + ที่อยู่ `30/2` วาด **เป็นภาพ/outline** (เหมือนงานจริง)
     2 แบบ: (ก) ตาเห็น `30/2` · (ข) ตาเห็น `2/30`
   * เพิ่มเศษส่วน `1/2` และเลขที่ลำดับกลับไม่ได้ความหมาย (`100/101`)
   * ⚠️ ต้องใช้ฟอนต์อาหรับจริงที่มีบนสถานี และตรวจภาพที่เรนเดอร์ **ด้วยตา** ก่อนใช้
2. **ยิง N8N OCR บนสถานี** (ใน container ไม่มี Gemini) แบบละ ≥ 5 รอบ
   ผ่าน `ocr_n8n.ocr_image` (เส้นทางเดียวกับของจริง) — บันทึกข้อความดิบ
3. **เล่นซ้ำงาน Dolphin จริง** — ข้อความ OCR ของสถานี 2 รอบที่มีอยู่แล้วให้ `2/30`
   ทั้งสองฝั่ง (นิ่ง 2/2) ⇒ ต้องการตัวอย่างมากกว่านี้
4. **เกณฑ์ผ่าน Phase 0 (ต้องครบทุกข้อ):**
   * Gemini คืนลำดับ **ตรงกับภาพ** ≥ 95% ของรอบ ทั้งแบบ (ก) และ (ข)
   * ข้ามรอบ **นิ่ง** (รอบเดียวกันภาพเดียวกันได้ลำดับเดียวกัน)
   * ต้นแบบของกติกา (B.4) บนธนาคาร 11 ชุด: **เตือนเฉพาะ Dolphin** · อื่น ๆ **0**
5. **ไม่ผ่าน ⇒ หยุด** แล้วรายงานผู้ใช้พร้อมตัวเลข (ไม่ทำ "แบบหลวม ๆ" แทน)

### B.4 การออกแบบ (ทำเมื่อ Phase 0 ผ่าน + ผู้ใช้ตอบ B.2 แล้ว)

**ที่อยู่:** โมดูลใหม่ `artwork_check/bidi_numbers.py` (ไม่ import Flask) เรียกจาก
ท้าย `checks.run_all_checks` **หลังชั้นพยาน** — เพิ่มรายการใหม่เท่านั้น ไม่แตะรายการเดิม

**ธง:** `ARTWORK_BIDI_NUMBER_ORDER` — **ค่าเริ่มต้นปิด** ระหว่างทดลองบนสถานี
(กฎเหล็ก 1) · เปิดเป็นค่าเริ่มต้นเมื่อยืนยันบนสถานีแล้วเท่านั้น

**กติกา (ต้นแบบ — ปรับตามผล Phase 0):**
1. แยก **ต่อไฟล์** (`doc` a / b) — เทียบภายในไฟล์เดียวกันเท่านั้น
2. ต่อบรรทัดของทุกโซน `panel`/`header` ที่อ่านออก: หา token
   `(?<![\d/.,])(\d{1,4})\s*/\s*(\d{1,4})(?![\d/.,])` จาก **ข้อความดิบ**
   (พับเลขอาหรับ-อินดิก `٠-٩` `۰-۹` เป็น `0-9` ก่อน — กับดักที่เจอในชั้นกรอบแดงแล้ว)
3. จัดชนิดบรรทัดจาก **อักษรแท้ส่วนใหญ่**: RTL (อาหรับ/ฮีบรู) · LTR (ละติน/ไทยตาม B.2)
4. **เตือนเมื่อ:** มี `a/b` ในบรรทัด RTL **และ** `b/a` ในบรรทัด LTR ของไฟล์เดียวกัน
   **และ** `a ≠ b` **และ** ไม่มี `a/b` ในบรรทัด LTR (ถ้ามีทั้งสองลำดับ = กำกวม ⇒ เงียบ)
5. **ไม่เตือน:** `a` หรือ `b` ≤ 12 ทั้งคู่ (แยกจากวันที่ `dd/mm` ไม่ได้) — ต้องวัดว่า
   ตัดเศษส่วน `1/2` ↔ `2/1` ทิ้งไปด้วย ยอมได้ไหม · เลขที่มี 3 ส่วน (`12/03/2026`)
6. ถ้ามีหลายคู่ในไฟล์เดียว ⇒ การ์ดแยกต่อคู่ (ไม่ยุบ — บทเรียน "ยุบเส้นประ")

**การ์ด:** คลาสใหม่ (เช่น `ORDER_BIDI`) ⇒ **ต้องเพิ่มครบ 4 ที่**:
`config.DEFECT_CLASSES` · `report._CLASS_COLORS_BGR` · `CLASS_LABELS` ใน
`artwork_check.js` · เทสต์ที่ไล่ทั้งสามให้ตรงกัน (+ CSS ถ้ามีคลาสใหม่ ครบ 2 template)
* ข้อความ: *"บรรทัดอาหรับพิมพ์ `2/30` แต่บรรทัดอังกฤษในไฟล์เดียวกันพิมพ์ `30/2` —
  โปรดให้ผู้อ่านภาษาอาหรับยืนยันลำดับ"* · **ห้ามบอกว่าฝั่งไหนผิด**
* `found` = บรรทัด RTL · `reference` = บรรทัด LTR · `found_spans`/`ref_spans`
  ชี้ที่ token ตัวเลข ⇒ ได้ไฮไลต์ + กรอบแดงจากกลไกเดิม (ช่องข้อความได้
  `dir="auto"` อยู่แล้วจากงาน 27 ก.ย.)
* `check_coverage` — เพิ่มชั้นนี้ในรายงาน "ตรวจอะไรไปบ้าง" (`ran`/`reason`)
  ⚠️ เงื่อนไขต้องสะท้อนตัวตรวจเป๊ะ (บทเรียน coverage 17 ส.ค.)

### B.5 เทสต์ + mutation (ขั้นต่ำ)

* ธนาคารเคส: Dolphin ได้การ์ดนี้ **ทั้งฝั่ง z และ b** · 10 ชุดอื่น **0 ใบ** · ธงปิด = เดิมทุกไบต์
* ตัวอย่างลบจาก B.1 ทุกตัว (เศษส่วน · `100/101` · `#05-02/03` · ไทย `999/9`)
* วันที่ `12/03` ↔ `03/12` ⇒ เงียบ · เลขอาหรับ-อินดิก `٣٠/٢` ⇒ จับได้เหมือน `30/2`
* สองลำดับอยู่ในบรรทัด LTR พร้อมกัน ⇒ เงียบ (กำกวม)
* ข้ามไฟล์ (อาหรับอยู่ไฟล์ a · อังกฤษอยู่ไฟล์ b) ⇒ เงียบ
* ระดับ = ค่าที่ผู้ใช้เลือก · verdict ไม่เปลี่ยนเมื่อระดับเป็น info
* ย้อนโค้ดทีละด่าน (ถอดด่านวันที่ / ด่านกำกวม / ด่านไฟล์เดียวกัน / ใช้ `_norm_key` /
  ไม่พับเลขอาหรับ-อินดิก / ไม่สนธง) ⇒ **แดงทุกจุด**

### B.6 ยืนยันบนสถานี

1. เปิดธง → ส่งตรวจ Dolphin ⇒ ได้การ์ดเตือน + ไฮไลต์ `2/30` / `30/2` · verdict เท่าเดิม
2. ส่งตรวจงานอื่นที่มีอาหรับ (John West · PURINA ONE) ⇒ **0 การ์ดเตือน**
3. เก็บผลทุกงานที่มีการ์ดนี้เข้าธนาคาร (A.3) ก่อนพิจารณาเปิดเป็นค่าเริ่มต้น

### B.7 ⛔ ห้าม
